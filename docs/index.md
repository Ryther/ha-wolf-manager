> safe or correct. The host toolkit changes Wolf/Steam configuration and runs
> root-controlled installation and service operations. Keep independent backups
> of Steam saves/libraries, Wolf identity/pairings and manager state, and try a
> disposable installation before using it on important data. Upstream and
> vendored dependencies retain their own authorship and licenses.

Manage multiple Wolf PCs from Home Assistant Ingress or an authenticated
standalone HTTPS dashboard. The Rust manager uses restricted, host-key-pinned SSH
to independently installed Rust PC tools. Ansible is not required.

## What do you want to do?

- **[Choose and install a manager](guides/index.md):** Select the Supervisor add-on
  or standalone Docker, then complete authentication and protected storage setup.
- **[Prepare your first PC](guides/host-installation.md):** Record existing mappings,
  preview install/adopt, authorize the restricted SSH key and verify its fingerprint.
- **[Use controls and game settings](guides/operations.md):** Check actual state,
  desired/staged/running revisions and operation outcomes before starting a session.
- **[Back up, restore or reset a password](guides/backup-recovery.md):** Preserve
  matching manager state and separate Steam/Wolf data before a change.
- **[Fix a problem](guides/troubleshooting.md):** Inspect health, structured logs,
  SSH/MQTT connectivity and uncertain operations without replaying them.

## Versions and support

The guides describe the repository's current experimental implementation.
If the [public release list](https://github.com/Ryther/ha-wolf-manager/releases)
is empty, there is no installable release yet. A draft, tag or passing check
does not establish that its image or archives are publicly available. Use only independently verified published artifacts and
compare these guides with your installed version's
[release notes](https://github.com/Ryther/ha-wolf-manager/releases).
Experimental 0.x interfaces may change through release-noted updates.

For help, start with troubleshooting, then report a sanitized reproduction in
[GitHub Issues](https://github.com/Ryther/ha-wolf-manager/issues).
[Security reporting](https://github.com/Ryther/ha-wolf-manager/blob/main/SECURITY.md)
is separate from public support. Never attach secrets, raw state or recovery bundles.
AI assistants can use the self-contained
[application guide skill](https://github.com/Ryther/ha-wolf-manager/blob/main/.agents/skills/ha-wolf-manager-guide/SKILL.md).
